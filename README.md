# 旅汇 · 旅行换算

一个以马币（MYR）为基准的旅行货币换算 PWA。每趟旅行使用一种外币，并根据实际兑换记录计算加权汇率：

`MYR 总支出 ÷ 外币总收入 = 每单位外币的马币成本`

## 功能

- 即时把当地价格换算为马币
- 为每趟旅行记录多笔兑换，并编辑或删除记录
- 创建、切换、编辑和删除旅行
- 离线优先，数据保存在当前设备的浏览器本地存储中
- 手机优先的响应式界面

## 本地运行

使用任意静态文件服务器提供此目录。PWA 安装和 Service Worker 离线缓存需要 `localhost` 或 HTTPS；通过 `file://` 打开时，界面和本地存储仍可使用，但 Service Worker 不会启用。

应用入口：`index.html`
